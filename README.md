 📱 Quick Start

1. **Open** `vegam_reader.html` in any modern browser.
2. **Paste text** or **upload PDF** in the welcome screen.
3. **Adjust controls**:
   | Control | What it does | Recommended |
   |---------|--------------|-------------|
   | **Fixation** (1-6) | How many letters bolded per word | 2-3 |
   | **WPM** (100-800) | Pacer speed | 250-400 |
   | **Pacer** | Moving focus line | ON |
   | **Zen** | Single‑para focus | ON for deep reads |
   | **Pause** | Freeze session timer | Use freely |
4. **Hit "Enter Reader"** → Start building your vivegam.

Demo text loads automatically for testing.
